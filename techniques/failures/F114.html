Failure of Success Criterion 1.4.13 Content on hover or focus when content cannot be dismissed without moving the pointer or the keyboard focus

ID: F114

Technology: failures

Type: Failure

When to Use

Applies when the user, by hovering over parts of content or by focusing an element via the keyboard, causes popup content to appear that cannot be dismissed without moving the pointer or keyboard focus (depending on how the popup was triggered).

Description

Content elements may respond to receiving keyboard focus or pointer hover by inserting additional popup content that may now cover other parts of content. Especially for page magnification users, this popup that can be problematic. Traditionally, screen magnification follows/centers on the current mouse or keyboard focus location. If new popup content appears on hover or focus, it may cover and obscure the content that the user was trying to view, and they won't be able to move their pointer or focus elsewhere while simultaneously moving their magnification viewport back to the content they originally wanted to see. For this reason, it is important that there is an easy way to dismiss such popup content, without having to move the pointer or focus. The most common method is for that is to press the Esc key. In the absence of such a mechanism, content fails the criterion. The only exception is when the popup content does not obscure or replace other existing content – for instance, when the popup appears over an area of whitespace or purely decorative content.

Examples

  • Custom tooltip: When focussing an icon with a question mark that is placed after an input field, a popup with an explanation of the expected input appears that covers a part of the form. Pressing the Esc key fails to close it.
  • Sub-menu: When the mouse pointer is moved over the entry in a horizontal menubar, a submenu appears. Pressing the Esc key fails to close the submenu.

Tests

Procedure

  1. Using the Tab key, navigate through interactive content. If popup content appears that hides information, verify if there is a way to close the popup with the keyboard without moving focus, such as pressing the Esc key.
  2. Move the pointer over interactive elements. If popup content appears that hides information, verify if there is a way to close the popup with the keyboard without moving the pointer, such as pressing the Esc key.

Expected Results

  • If #1 or #2 is false, then content fails the success criterion.
