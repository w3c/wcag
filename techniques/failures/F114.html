Failure of Success Criterion 1.4.13 Content on hover or focus when content cannot be dismissed without moving the pointer or the keyboard focus

ID: F114

Technology: failures

Type: Failure

When to Use

Applies when the user, by hovering over parts of content or by focusing an element via the keyboard, causes popup content to appear that cannot be dismissed without moving the pointer or keyboard focus (depending on how the popup was triggered).

Description

This describes a failure condition when additional content is displayed on hover or focus, but there is no mechanism to dismiss it without moving the pointer or the keyboard focus.

Examples

  • Custom tooltip: When focusing an icon with a question mark that is placed after an input field, a popup with an explanation of the expected input appears that covers a part of the form. The only way to close the popup is to Tab / move focus away from the question mark icon.
  • Sub-menu: When the mouse pointer is moved over a menu item in a horizontal menubar, a sub-menu appears. The only way to close the sub-menu is to move the pointer away from the menu item.

Tests

Procedure

  1. Using the Tab key, navigate through interactive content. If popup content appears that hides information, verify if there is a way to close the popup with the keyboard without moving focus, such as pressing the Esc key.
  2. Move the pointer over interactive elements. If popup content appears that hides information, verify if there is a way to close the popup with the keyboard without moving the pointer, such as pressing the Esc key or clicking the pointer (without activating any additional functionality).

Expected Results

  • If #1 or #2 is false, then content fails the success criterion.
